# Smoke — sr2-37: orchestrator empty-response guard

Proves: an empty LLM response mid-turn is retried once, and a double-empty turn ends with a visible `[empty model response]` instead of silence.
Caveat: uses a scripted fake LLM, not the real qwen3.6 endpoint — it does NOT prove the live model's flake rate, only the orchestrator's handling.

## Setup

```
mkdir -p /tmp/sr2-37-smoke
```

```
cat > /tmp/sr2-37-smoke/smoke.py <<'EOF'
import asyncio
import sys
sys.path.insert(0, "/home/shepard/git/sr2/tests")
from conftest import SequentialMockLLM, make_minimal_config, make_user_input
from sr2.orchestrator import SR2
from sr2.protocols.llm import StreamEvent
from sr2.pipeline.token_counting import CharacterTokenCounter

EMPTY = [StreamEvent(type="end")]
TEXT = [StreamEvent(type="text", text="recovered fine"), StreamEvent(type="end")]

async def run(sequences, label):
    llm = SequentialMockLLM(sequences)
    sr2 = SR2(pipeline_config=make_minimal_config(), llm={"default": llm}, token_counter=CharacterTokenCounter())
    texts = []
    async for ev in sr2.turn(make_user_input("hello")):
        if ev.type == "text" and ev.text:
            texts.append(ev.text)
    print(f"{label}: calls={len(llm.stream_calls)} text={''.join(texts)!r}")

asyncio.run(run([EMPTY, EMPTY], "double-empty"))
asyncio.run(run([EMPTY, TEXT], "empty-then-text"))
asyncio.run(run([TEXT], "normal"))
EOF
```

## Scenario 1 — guard behavior (all three shapes)

**Expect**: WARNING lines about empty responses, then exactly these three result lines:
