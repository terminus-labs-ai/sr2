# SR2

SR2 development has moved to the [spctr monorepo](https://github.com/terminus-labs-ai/spctr).

The core library is maintained in [`packages/sr2`](https://github.com/terminus-labs-ai/spctr/tree/main/packages/sr2). Its Python package name remains `sr2`; spctr is the agent runtime built on it.

Use the [current repository](https://github.com/terminus-labs-ai/spctr) for installation instructions, issues and contributions. This repository preserves the original SR2 history.
